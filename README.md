## 🚀 Key Features | الميزات الرئيسية

### 📱 1. Smart Digital Menu (Customer & Captain Interface) | المنيو الرقمي الذكي
- **QR Code Integration**: Customers can scan and view the interactive menu instantly.
  *(مسح رمز الاستجابة السريعة لعرض المنيو التفاعلي في ثوانٍ).*
- **Quick Order Customization**: Seamless modifications (e.g., Sugar levels, Ice, Notes) directly from the interface.
  *(تخصيص الطلبات بسهولة مثل مستويات السكر والإضافات).*

### 🖥️ 2. Cashier Operations & Shift Management | عمليات الكاشير وإدارة الورديات (الشيفتات)
- **Shift Control**: Open and close shifts with automated expected cash mapping and discrepancy tracking.
  *(فتح وإغلاق الشيفتات مع حساب العجز والزيادة بشكل آلي وبدقة عالية).*
- **Instant Receipt Printing**: Optimized for 80mm thermal printers with custom café branding.
  *(طباعة فورية للفواتير متوافقة مع طابعات 80 مل).*
- **Multiple Payment Gateways**: Cash, InstaPay, and Mobile Wallets support with digital proof verification.
  *(دعم الدفع النقدي، إنستاباي، والمحافظ الإلكترونية مع رفع إيصال التحويل للمراجعة).*

### 📊 3. Admin & Analytics Dashboard | لوحة تحكم الإدارة والإحصائيات
- **Real-Time Data**: Monitor sales, open tables, and live orders globally.
  *(متابعة المبيعات والطاولات المفتوحة والطلبات الحية لحظة بلحظة).*
- **Financial Control**: Deep dive into revenue, accounting, supplier expenses, and profitability.
  *(تحكم مالي شامل يشمل الإيرادات، المصروفات، حسابات الموردين والأرباح).*

### 📦 4. Inventory & Staff Management | إدارة المخزون والموظفين
- **Stock Tracking**: Prevent shortages with automated inventory deductions and alert thresholds.
  *(تتبع المخزون بشكل دقيق لمنع النواقص، مع تنبيهات ذكية).*
- **Role-Based Access**: Granular permissions for Admins, Cashiers, Captains, and Kitchen Staff.
  *(صلاحيات دقيقة مخصصة للإدارة، الكاشير، الكابتن، وطاقم المطبخ).*

## 🛠️ Technology Stack | التقنيات المستخدمة
- **Frontend / واجهة الاستخدام**: React.js & Tailwind CSS for unmatched performance and UI/UX magic.
- **Backend & Database / قواعد البيانات**: Firebase Firestore for real-time document sync.
- **State Management / إدارة الحالة**: Zustand for lightning-fast global states.
- **UI Architecture / المؤثرات البصرية**: Framer Motion for buttery-smooth animations.
